# Indice

## [Módulo 1 Introducción a JavaScript del lado del servidor](./Módulo-1/index.md)

Puede que ya esté familiarizado con JavaScript, pero ¿sabía que existe un framework JavaScript del lado del servidor? Descubra cómo se utiliza Node.js en el back-end para desarrollar aplicaciones web ricas y dinámicas importando módulos externos y utilizando el gestor de paquetes Node (NPM).obtenga experiencia práctica utilizando Node.js para construir su propio servidor web sencillo.

## [Módulo 2 E/S asíncrona con programación de devolución de llamada](./Módulo-2/index.md)

¿Cómo puede optimizar el tiempo de procesador con Node.js? Descubra cómo funciona Node.js de forma no bloqueante y cómo manejar el resultado de una llamada de red. Explore las ventajas y los retos asociados al uso de funciones anónimas de devolución de llamada. Utilice Node.js para analizar datos de Notación de Objetos JavaScript (JSON) a partir de un mensaje de Protocolo de Transferencia de Hipertexto (HTTP).

## [Módulo 3 Marco de aplicaciones web Express](./Módulo-3/index.md)

Cuando utilice Node.js para construir un servidor de protocolo de transferencia de hipertexto (HTTP), descubrirá que el framework Node.js por defecto es de bajo nivel. Puede ampliar sus características con paquetes de terceros como Express. Obtenga experiencia práctica con el marco de aplicaciones web Express creando un servidor web que escuche las solicitudes entrantes. También aprenderá a implementar la autorización con Express. Utilice el enrutamiento, el middleware y el renderizado de plantillas para ampliar el marco Node.js y manejar contenido dinámico.
