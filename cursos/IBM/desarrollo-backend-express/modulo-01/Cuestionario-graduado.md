# Cuestionario graduado

¿Cuál de las siguientes es una tecnología back-end?

1. CSS
2. **API web**
3. HTML
4. Navegador

¿Qué cualidad le permite ejecutar aplicaciones JavaScript sin compilar?

1. **JavaScript es un lenguaje interpretado.**
2. Puede utilizar un editor de texto para desarrollar aplicaciones JavaScript.
3. La sintaxis del lenguaje se parece a la de Java.
4. Todos los navegadores modernos admiten JavaScript.

¿Cuál de las siguientes aplicaciones intercepta la llamada cuando JavaScript envía una solicitud de servicio web al servidor Node.js?

1. **Servicio web REST**
2. Java empresarial
3. CSS
4. JSON

¿Cuál de las siguientes es una diferencia entre los módulos ES y CommonJS?

1. CommonJS es un lenguaje JavaScript mientras que ES es una especificación de módulos
2. Los módulos CommonJS se escriben en JavaScript mientras que los módulos ES no
3. **Los módulos ES utilizan la sentencia import() mientras que los módulos CommonJS utilizan require().**
4. Los archivos de módulos CommonJS utilizan una extensión .mjs mientras que los módulos ES utilizan .js

¿Cómo se gestionan los resultados de las operaciones con Node.js?

1. **Escriba funciones de devolución de llamada para manejar los resultados cuando las operaciones finalicen**
2. Utilizar el bloqueo en operaciones de E/S asíncronas
3. Crear una instancia de una aplicación de servidor web
4. Especifique una ruta relativa al script Node.js desde el directorio del módulo

¿Para qué utiliza la función http.createServer?

1. Para especificar un script principal para su módulo
2. **Para crear una instancia de un servidor web**
3. Para importar un módulo Node.js
4. Desarrollar una función anónima para gestionar solicitudes y respuestas

¿Qué módulo del núcleo de Node.js puede utilizarse para la entrada y salida (E/S)?

1. util
2. URL
3. http
4. **fs**

¿Cuál es un aspecto de Node Package Manager (NPM)?

1. **Funciona como una interfaz de línea de comandos para instalar paquetes**
2. Crea un archivo package.json en el directorio raíz del proyecto
3. Escribe metadatos en un archivo package.json
4. Gestiona el versionado del código fuente

¿Para qué utiliza la función require?

1. Desarrollar una función anónima para gestionar solicitudes y respuestas
2. Para crear una instancia de un servidor web
3. **Para importar un módulo Node.js**
4. Para especificar un script principal para su módulo

¿Qué ocurre cuando un módulo no tiene un archivo package.json?

1. La sentencia require asume que los scripts tienen una extensión de archivo js.
2. **Node.js asume que la clase principal se llama index.js.**
3. La ruta relativa al script Node.js cambia a una ruta absoluta desde el directorio del módulo.
4. ~~No hay manifiesto de módulo.~~
