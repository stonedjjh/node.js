# Glosario: Introducción a JavaScript del lado del servidor

| Término                                                  | Definición                                                                                                                                                                                                                                                                                                                                      |
| :------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Anonymous Function (Función Anónima)**                 | Una función que no tiene nombre. Una función anónima a menudo se pasa a otra función como parámetro.                                                                                                                                                                                                                                            |
| **Application Server (Servidor de Aplicaciones)**        | Transforma datos en contenido dinámico y ejecuta la lógica empresarial, que son las reglas de almacenamiento y transferencia de datos.                                                                                                                                                                                                          |
| **Asynchronous (Asíncrono)**                             | Un proceso que se ejecuta independientemente de otros procesos.                                                                                                                                                                                                                                                                                 |
| **Callback Function (Función de Devolución de Llamada)** | Una función pasada a otra función como parámetro, que luego se invoca dentro de la función externa para completar una acción. En lugar de bloquear las operaciones de E/S asíncronas, las funciones de devolución de llamada se utilizan para manejar los resultados cuando se completan las operaciones.                                       |
| **Database Server (Servidor de Base de Datos)**          | Un servidor dedicado a proporcionar servicios de base de datos.                                                                                                                                                                                                                                                                                 |
| **Dependencies (Dependencias)**                          | Código, generalmente en forma de bibliotecas y paquetes, que se invocan desde otros módulos y se reutilizan en un programa.                                                                                                                                                                                                                     |
| **Event-Driven (Dirigido por Eventos)**                  | Donde el flujo de un programa está determinado por eventos particulares, como la entrada del usuario.                                                                                                                                                                                                                                           |
| **Express.js**                                           | Un marco de trabajo web altamente configurable para construir aplicaciones en Node.js.                                                                                                                                                                                                                                                          |
| **Framework (Marco de Trabajo)**                         | Genera código que no puede ser alterado para realizar tareas comunes. Ejemplos incluyen Django, Ruby on Rails y Express.js.                                                                                                                                                                                                                     |
| **HTTP Server (Servidor HTTP)**                          | Un tipo de servidor basado en software que entiende las URLs y el protocolo de transferencia de hipertexto.                                                                                                                                                                                                                                     |
| **Load (Carga)**                                         | Se refiere al número de usuarios concurrentes, el número de transacciones y la cantidad de datos transferidos de un lado a otro entre los clientes y los servidores.                                                                                                                                                                            |
| **Module (Módulo)**                                      | Archivos que contienen código JavaScript relacionado y encapsulado que sirven para un propósito específico.                                                                                                                                                                                                                                     |
| **Multi-Threaded (Multihilo)**                           | Donde se ejecutan múltiples tareas simultáneamente.                                                                                                                                                                                                                                                                                             |
| **Node.js**                                              | Un entorno de ejecución de JavaScript que funciona sobre el motor V8 de Google Chrome.                                                                                                                                                                                                                                                          |
| **Non-Blocking (No Bloqueante)**                         | El fallo de un hilo determinado no causa el fallo en otro, y la ejecución de una tarea no se bloquea hasta que se complete la ejecución de otra tarea.                                                                                                                                                                                          |
| **Npm**                                                  | Siglas de Node Package Manager (Gestor de Paquetes de Node). Es el gestor de paquetes predeterminado para el entorno de ejecución Node.js.                                                                                                                                                                                                      |
| **Package (Paquete)**                                    | Un directorio con uno o más módulos agrupados.                                                                                                                                                                                                                                                                                                  |
| **Package.json**                                         | Contiene información de metadatos sobre el proyecto, incluyendo dependencias y scripts.                                                                                                                                                                                                                                                         |
| **Payload (Carga Útil)**                                 | Los datos transmitidos entre el cliente y el servidor.                                                                                                                                                                                                                                                                                          |
| **Runtime Environment (Entorno de Ejecución)**           | Se comporta de manera similar a un mini sistema operativo que proporciona los recursos necesarios para que una aplicación se ejecute. Es la infraestructura que soporta la ejecución de una base de código. Es el entorno de hardware y software en el que se ejecuta una aplicación. Node.js es un ejemplo de un entorno de ejecución backend. |
| **Scalability (Escalabilidad)**                          | La capacidad de la aplicación para manejar dinámicamente la carga tal cual es o reducirse sin que ello afecte al rendimiento de la aplicación.                                                                                                                                                                                                  |
| **Server.js**                                            | Un archivo que contiene el código que maneja la creación del servidor.                                                                                                                                                                                                                                                                          |
| **Single-Threaded (Monohilo)**                           | Donde solo se procesa un comando en un momento determinado.                                                                                                                                                                                                                                                                                     |
| **Web Server (Servidor Web)**                            | Asegura que se responda a las solicitudes de los clientes, a menudo utilizando HTTP.                                                                                                                                                                                                                                                            |
| **Web Service (Servicio Web)**                           | Un tipo de API web que se comunica mediante solicitudes HTTP. Es el servicio web en la interfaz de programación que envía y recibe solicitudes mediante HTTP entre los servidores web y el cliente.                                                                                                                                             |
