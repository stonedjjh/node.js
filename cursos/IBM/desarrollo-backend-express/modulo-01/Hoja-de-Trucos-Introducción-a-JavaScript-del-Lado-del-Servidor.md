# Hoja de Trucos: Introducción a JavaScript del Lado del Servidor

| Paquete/Método        | Descripción                                                                                                                                                                                                                                                                                                                                                     | Ejemplo de Código                                                                                                                                                                                                                                                                                                            |
| :-------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **http/createServer** | El paquete http se utiliza para establecer conexiones remotas a un servidor o para crear un servidor que escuche a un cliente. **createServer** - Toma un requestListener, una función que recibe parámetros de solicitud y respuesta, donde la solicitud es el manejador de la solicitud del cliente y la respuesta es el manejador que se enviará al cliente. | `const http = require('http');`<br>`const requestListener = function(req, res) {`<br>`  res.writeHead(200);`<br>`  res.end('¡Hola, Mundo!');`<br>`}`<br>`const port = 8080;`<br>`const server = http.createServer(requestListener);`<br>`console.log('servidor escuchando en el puerto: '+ port);`<br>`server.listen(port);` |
| **new Date()**        | El método new Date() devuelve la fecha actual como un objeto. Puedes invocar métodos en el objeto de fecha para formatearlo o cambiar la zona horaria.                                                                                                                                                                                                          | `module.exports.getDate = function getDate() {`<br>`    let aestTime = new Date().toLocaleString("en-US", {timeZone: "Australia/Brisbane"});`<br>`    return aestTime;`<br>`}`                                                                                                                                               |
| **import()**          | La declaración import se utiliza para importar módulos que algún otro módulo ha exportado. Un archivo que incluye código reutilizable se conoce como un módulo.                                                                                                                                                                                                 | `// addTwoNos.mjs`<br>`function addTwo(num) { return num + 4; }`<br>`export { addTwo };`<br>`// app.js`<br>`import { addTwo } from './addTwoNos.mjs';`<br>`console.log(addTwo(4)); // Imprime: 8`                                                                                                                            |
| **require()**         | El método incorporado de NodeJS require() se utiliza para incorporar módulos externos que están incluidos en diferentes archivos. La declaración require() esencialmente lee y ejecuta un archivo JavaScript antes de devolver el objeto de exportación.                                                                                                        | `module.exports = 'Hola Programadores';`<br>`let msg = require('./messages.js');`<br>`console.log(msg);`                                                                                                                                                                                                                     |
