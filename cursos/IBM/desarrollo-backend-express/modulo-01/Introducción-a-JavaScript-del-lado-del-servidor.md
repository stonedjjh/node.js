# Introducción a JavaScript del lado del servidor

JavaScript es un lenguaje interpretado que no requiere compilación previa para ejecutarse. Originalmente diseñado para añadir dinamismo a sitios web estáticos en navegadores, hoy puede ejecutarse en diversos servidores y sistemas integrados.

## JavaScript del lado del cliente vs. del lado del servidor

### Lado del Cliente (Client-side)

- **Interfaz:** Se renderiza mediante HTML y CSS en el navegador del usuario.
- **Lógica:** Las acciones del usuario activan lógica empresarial escrita en JavaScript.
- **Comunicación:** Envía solicitudes mediante JSON a través del protocolo HTTP.
- **Backend Tradicional:** Las solicitudes suelen ser procesadas por servicios escritos en Java, PHP u otros lenguajes de fondo.

### Lado del Servidor (Server-side) con Node.js

- **Procesamiento:** Utiliza Node.js para procesar y enrutar las solicitudes de servicios web desde el cliente.
- **Lenguaje Unificado:** A diferencia del modelo tradicional, el servidor aloja una aplicación escrita también en JavaScript.
- **Ejecución:** El código se ejecuta directamente en el servidor y no en el navegador web del cliente.

## Beneficios de Node.js

Node.js es un marco de programación que permite a los desarrolladores crear aplicaciones de servidor simultáneas y escalables de forma rápida utilizando un conjunto mínimo de herramientas.
