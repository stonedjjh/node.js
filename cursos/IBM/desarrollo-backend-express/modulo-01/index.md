# Introducción a JavaScript del lado del servidor

Puede que ya esté familiarizado con JavaScript, pero ¿sabía que existe un framework JavaScript del lado del servidor? Descubra cómo se utiliza Node.js en el back-end para desarrollar aplicaciones web ricas y dinámicas importando módulos externos y utilizando el gestor de paquetes Node (NPM).obtenga experiencia práctica utilizando Node.js para construir su propio servidor web sencillo.

## Objetivos de aprendizaje

- Utilice npm para gestionar los paquetes Node.js en su aplicación Node.js.
- Compare y contraste una instalación local de NPM con una instalación global de NPM.
- Diferencie entre módulos centrales, locales y de terceros.
- Exporte funciones y propiedades de un módulo.
- Escriba un servidor web sencillo con Node.js.
- Explique la finalidad del framework JavaScript Node.js.
- Explique las diferencias entre JavaScript del lado del cliente y JavaScript del lado del servidor.
- Diferencie entre las sentencias import y require.
- Describa el papel de Node.js para el scripting del lado del servidor.
  Explique los componentes del backend de una aplicación web.
