# Glosario: E/S asíncrona con programación de devolución de llamada

| Término                                                 | Definición                                                                                                                                                                                                                                                                                                                                                |
| :------------------------------------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Async**                                               | Abreviatura de "asíncrono".                                                                                                                                                                                                                                                                                                                               |
| **Paquete Axios**                                       | El paquete axios envuelve promesas alrededor de las solicitudes HTTP. Devuelve un objeto de promesa.                                                                                                                                                                                                                                                      |
| **Infierno de devoluciones de llamada (Callback Hell)** | Gran cantidad de funciones de devolución de llamada anidadas.                                                                                                                                                                                                                                                                                             |
| **Inversión de Control**                                | Cuando el flujo de control, como la ejecución de instrucciones, es controlado por un tercero.                                                                                                                                                                                                                                                             |
| **Promesa (Promise)**                                   | Un objeto en JavaScript que actúa como un marcador de posición para una tarea asíncrona que aún no se ha completado. Es el objeto que devuelve un método asíncrono. Cuando defines un objeto de promesa en tu script, en lugar de devolver un valor inmediatamente, devuelve una promesa. La promesa tiene tres estados: pendiente, cumplida y rechazada. |
| **Pirámide de la perdición (Pyramid of Doom)**          | Otro término para referirse al "infierno de devoluciones de llamada" (callback hell).                                                                                                                                                                                                                                                                     |
