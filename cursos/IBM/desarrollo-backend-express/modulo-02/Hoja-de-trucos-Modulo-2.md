# Hoja de trucos del Módulo 2: E/S Asincrónica con Programa de Callback

| Paquete/Método                                | Descripción                                                                                                                                                                                                                   | Ejemplo de Código                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| :-------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Async-await**                               | Podemos esperar promesas siempre que se llamen dentro de funciones asincrónicas.                                                                                                                                              | `const axios = require('axios').default; let url = "some remote url" async function asyncCall() {   console.log('calling');   const result = await axios.get(url);   console.log(result.data); } asyncCall(); `                                                                                                                                                                                                                                                      |
| **Callback**                                  | Los callbacks son métodos que se pasan como parámetros. Se invocan dentro del método al que se pasan como parámetro, condicional o incondicionalmente. Usamos callbacks con una promesa para procesar la respuesta o errores. | `//function(res) y function(err) son las funciones de callback anónimas axios.get(url).then(function(res) {     console.log(res); }).catch(function(err) {     console.log(err) }) `                                                                                                                                                                                                                                                                                 |
| **Promise**                                   | Un objeto que es devuelto por algunos métodos, representando una eventual finalización o fallo. El código continúa ejecutándose sin bloquearse hasta que la promesa se cumple o se lanza una excepción.                       | `axios.get(url).then( //hacer algo ).catch( //hacer algo )  `                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Caso de uso de Promise**                    | Las promesas se utilizan cuando el tiempo de procesamiento de la función que invocamos toma tiempo, como el acceso a una URL remota, operaciones de I/O, lectura de archivos, etc.                                            | `let prompt = require('prompt-sync')(); let fs = require('fs'); const methCall = new Promise((resolve,reject)=>{     let filename = prompt('¿Cuál es el nombre del archivo?');     try {       const data = fs.readFileSync(filename, {encoding:'utf8', flag:'r'});       resolve(data);     } catch(err) {       reject(err)     } }); console.log(methCall); methCall.then(   (data) => console.log(data),   (err) => console.log("Error al leer el archivo") ); ` |
| **object.on()**                               | Define un controlador de eventos que el marco llama cuando ocurre un evento                                                                                                                                                   | `http.request( options, function(response) {  let buffer = ‘’;  ...  response.on('data', function(chunk) {    buffer += chunk;  });  response.on('end', function() {    console.log(buffer);  }); }).end(); `                                                                                                                                                                                                                                                        |
| **Callback Hell/La Pirámide de la Perdición** | Callbacks anidados apilados uno debajo del otro y esperando el callback anterior. Esto crea una estructura de pirámide que afecta la legibilidad y mantenibilidad del código.                                                 | `const makeCake = nextStep => {   buyIngredients(function(shoppingList) {     combineIngredients(bowl, mixer, function(ingredients){       bakeCake(oven, pan, function(batter) {         decorate(icing, function(cake) {           nextStep(cake);         });       });     });   }); }; `                                                                                                                                                                        |
| **Solicitud de Axios**                        | El paquete axios maneja solicitudes HTTP y devuelve un objeto de promesa.                                                                                                                                                     | `const axios = require('axios').default; const connectToURL=(url)=>{   const req=axios.get(url);   console.log(req);   req.then(resp=>{   console.log("Cumplido");   console.log(resp.data);   })   .catch(err=>{   console.log("Rechazado");   }); } connectToURL('valid-url') connectToURL('invalid-url') `                                                                                                                                                        |
