# E/S asíncrona con programación de devolución de llamada

¿Cómo puede optimizar el tiempo de procesador con Node.js? Descubra cómo funciona Node.js de forma no bloqueante y cómo manejar el resultado de una llamada de red. Explore las ventajas y los retos asociados al uso de funciones anónimas de devolución de llamada. Utilice Node.js para analizar datos de Notación de Objetos JavaScript (JSON) a partir de un mensaje de Protocolo de Transferencia de Hipertexto (HTTP).

## Objetivos de aprendizaje

- Explique el concepto de funciones de devolución de llamada asíncronas.
- Explique las dificultades con las devoluciones de llamada anidadas y la inversión de control.
- Cree una función de devolución de llamada para interceptar las llamadas al método HTTP.
- Describa cómo el objeto promesa de JavaScript representa la finalización eventual de una operación asíncrona y su valor de retorno.
- Analice los datos JSON de un mensaje HTTP.
