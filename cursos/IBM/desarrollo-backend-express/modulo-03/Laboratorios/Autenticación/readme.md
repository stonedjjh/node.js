# Instrucciones

1. Ejecute `node server.js`

2. Verifique que no se puede acceder al menos que este autenticado, en la terminal ejecute `curl -i localhost:5000/employee`

3. Se usara la librería `jsonwebtoken` para la administración del token en la terminal ejecute: `pnpm isntall save jsonwebtoken`

> [!NOTE]
> Puede usar el instaladore de paquetes de su preferencia
