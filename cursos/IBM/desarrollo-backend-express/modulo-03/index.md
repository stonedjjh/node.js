# E/S asíncrona con programación de devolución de llamada

Cuando utilice Node.js para construir un servidor de protocolo de transferencia de hipertexto (HTTP), descubrirá que el framework Node.js por defecto es de bajo nivel. Puede ampliar sus características con paquetes de terceros como Express. Obtenga experiencia práctica con el marco de aplicaciones web Express creando un servidor web que escuche las solicitudes entrantes. También aprenderá a implementar la autorización con Express. Utilice el enrutamiento, el middleware y el renderizado de plantillas para ampliar el marco Node.js y manejar contenido dinámico.

## Objetivos de aprendizaje

- Amplíe Node.js con paquetes de terceros.
- Envíe una petición HTTP para obtener datos.
- Explique los estilos arquitectónicos MVC y API REST.
- Explique cómo utilizar bibliotecas para abstraer tareas de bajo nivel.
- Defina Express y explique cómo funciona.
- Importe el módulo Express y cree una aplicación Express.
- Utilice el enrutamiento, el middleware y las plantillas para gestionar las solicitudes de forma eficaz en actividades como la autenticación, la comprobación de la información de sesión y el relleno de contenido dinámico en aplicaciones front-end.
- Implemente autenticación y autorización basadas en tokens en Node.js.
